# داده‌های مشاوره رزم‌افزاری

این پوشه **فقط داده ساختاریافته JSON** نگه می‌دارد. API یا مدل Django جداگانه‌ای ندارد؛ داده از طریق `orchestrator` (در زمان اجرا و هنگام آموزش مدل Ollama) بارگذاری می‌شود.

**مهم:** در زمان اجرا داده از جدول `KnowledgeBase` خوانده می‌شود (نه مستقیم از فایل). بعد از ویرایش JSON حتماً seed کنید:

```bash
python3 manage.py seed_admin_data --force --knowledge-only
```

## JSON در برابر اسناد آپلودی

| منبع | کجا مدیریت می‌شود | چطور به مدل می‌رسد |
|------|-------------------|---------------------|
| JSON جغرافیا / نیرو / تسلیحات | فایل‌های این پوشه + Admin → Knowledge datasets | Context ساختاریافته در هر درخواست |
| TXT / PDF / Word | Admin → Knowledge Base → **Documents** | استخراج متن، chunk، بازیابی مرتبط در Context |

فایل‌های آپلودی در `media/knowledge_docs/` ذخیره می‌شوند (نه در این پوشه).

## فایل‌ها

| فایل | محتوا |
|------|--------|
| `geography/middle_east_geography.json` | زمین، آب‌وهوا، گلوگاه‌ها، ملاحظات نظامی |
| `personnel/middle_east_personnel.json` | نیرو، ذخیره، ساختار شاخه‌ها و رسته‌ها |
| `weapons/middle_east_weapons.json` | تسلیحات و موجودی کشورها |

## جغرافیا

برای هر کشور:

- **terrain** — نوع زمین، ارتفاع، سختی مانور
- **weather** — اقلیم، دما، بارش
- **strategic_features** — بنادر، فرودگاه‌ها، گلوگاه‌ها
- **military_considerations** — مزایا و معایب زمینی

همچنین الگوهای آب‌وهوایی منطقه‌ای و گلوگاه‌های راهبردی در سطح کل دیتاست تعریف شده‌اند.

**کشورها:** سوریه، عراق، ایران، اسرائیل، لبنان، اردن، عربستان، یمن، مصر، ترکیه

## نیروی انسانی

برای هر کشور:

- تعداد **نیروی فعال** و **ذخیره**
- شاخه‌ها: **ground_forces**، **air_force**، **navy**، **special_forces**
- در هر شاخه: رسته‌ها، درجات، تعداد و یگان‌های ویژه

**کشورها:** اسرائیل، ایران، ترکیه، مصر، عربستان، عراق، سوریه، لبنان، اردن، یمن

اعداد تقریبی و سبک منابع باز (Military Balance) هستند؛ برای یمن فرماندهی پس از جنگ داخلی تکه‌تکه است و در داده با `note` مشخص شده.

## تسلیحات

دسته‌های اصلی:

| دسته | نمونه |
|------|--------|
| individual_weapons | تفنگ، تک‌تیرانداز، ضدتانک |
| collective_weapons | تانک، جنگنده، پدافند هوایی، بالگرد، ناو، نفربر |
| robotics_ai_weapons | پهپاد |
| conventional_weapons | توپخانه، موشک بالستیک، موشک کروز |
| unconventional_weapons | IED |
| chemical/biological/nuclear_weapons | سلاح‌های غیرمتعارف |

هر نوع شامل مشخصات فنی و **توزیع بین کشورها** (تعداد کیفی و مدل‌های اصلی) است.

**کشورهای پوشش‌داده‌شده در بیشتر انواع:** ایران، اسرائیل، ترکیه، عربستان، مصر، عراق، سوریه، اردن، لبنان، یمن (+ امارات در برخی انواع قدیمی)

## ویرایش داده

1. فایل JSON مربوطه را ویرایش کنید (ساختار کلیدها را حفظ کنید).
2. داده را به دیتابیس منتقل کنید:

```bash
python3 manage.py seed_admin_data --force --knowledge-only
```

3. در صورت نیاز مدل Ollama را بازسازی کنید:

```bash
python3 manage.py retrain_wargaming_llm --force
```

راه‌اندازی کامل پروژه در [README اصلی](../README.md) توضیح داده شده است.
